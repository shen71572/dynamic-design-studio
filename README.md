# 动态设计工作室

20 个 GitHub 仓库 / 技能，让 Claude 变成专业级动态设计工作室：动画设计、3D、动画引擎、音频、视频渲染导出。

## 动画设计

| 项目 | 链接 | 用途 |
| --- | --- | --- |
| motion-design-skill | https://github.com/LottieFiles/motion-design-skill | 动画时序、缓动效果、迪士尼动画 12 原则 |
| Motion | https://github.com/motiondivision/motion | 弹簧运动效果、屏幕切换动画 |
| Remotion Skills | https://github.com/remotion-dev/skills | 视频制作专用技能 |
| hairline | https://hairline.lucasmarkes.com/skills | 根据创意或 SVG 制作可交互的动态线条 |
| anatomy-reveal | https://typingmind.com/skills/annnguyentt-anatomy-reveal | 产品拆解图、产品展示动画 |
| GSAP | https://github.com/greensock/GSAP | 专业动画时间轴，现在完全免费 |
